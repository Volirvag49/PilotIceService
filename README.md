# PilotIceService

**PilotIceService** — это специализированный Web API сервис, разработанный на платформе .NET, который выступает в роли интеграционного шлюза для взаимодействия с системой управления инженерными данными и проектированием **Pilot-ICE** (АСКОН). 

Проект построен по принципам **чистой архитектуры (Clean Architecture)**, что обеспечивает слабую связанность компонентов, простоту тестирования и гибкость расширения функционала интеграции.

---

## 🏗️ Архитектура проекта

Репозиторий разделен на логические слои:

*   **`PilotIceService.WebApi`** — уровень представления (Presentation Layer). Содержит контроллеры, конфигурации HTTP-маршрутов, Middleware и настройки Swagger/OpenAPI. Принимает внешние запросы.
*   **`PilotIceService.Application`** — уровень бизнес-логики (Application Layer). Содержит интерфейсы, CQRS-команды/запросы, DTO и логику обработки данных, независимую от внешних фреймворков.
*   **`PilotIceService.Infrastructure`** — уровень инфраструктуры (Infrastructure Layer). Отвечает за непосредственное взаимодействие со сторонними ресурсами: базами данных и низкоуровневым API/SDK системы Pilot-ICE.
*   **`PilotIceService.Contract`** — контракты данных. Общие интерфейсы, модели обмена данными и структуры, используемые между слоями или внешними клиентами.
*   **`ChangesListener`** — вспомогательный модуль/сервис (Background Worker), предназначенный для фонового прослушивания событий изменений данных на стороне Pilot-ICE и их синхронизации.

---

## 🚀 Функциональные возможности

*   **Унифицированный REST API** для интеграции Pilot-ICE с внешними корпоративными системами (ERP, CRM, 1С, BPM).
*   **Управление данными проектов**: создание, чтение, обновление и синхронизация проектной структуры и карточек документов.
*   **Работа с файлами**: выгрузка и загрузка инженерных данных и сопутствующей документации.
*   **Отслеживание изменений**: фоновый мониторинг событий в Pilot-ICE в реальном времени с помощью модуля `ChangesListener`.

## 🛠️ Технологический стек

*   **Платформа:** .NET 8.0+ / C# 100%
*   **Архитектурный шаблон:** Clean Architecture (Разделение ответственности)
*   **API:** ASP.NET Core Web API, Swagger/OpenAPI
*   **Интеграция:** Pilot-ICE SDK / Server API

---

## 📦 Быстрый старт

### Требования
1. Установленный .NET SDK (версии 8.0 или выше).
2. Доступ к развернутому серверу Pilot-Server (Pilot-ICE / Pilot-ICE Enterprise).
3. Настроенные клиентские библиотеки/SDK АСКОН Pilot в слое `Infrastructure`.


Проект распространяется в соответствии с правилами использования компонентов Pilot SDK. Подробности см. в файлах лицензии вашей редакции Pilot-ICE.
